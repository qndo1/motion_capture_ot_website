# Motion Capture for Occupational Therapy

A website for the UCSD Data Science Capstone project exploring the application of motion capture technology in occupational therapy settings.

## About

This project leverages advanced data science techniques and motion tracking systems to provide objective measurements and insights that can enhance patient assessment and treatment outcomes in occupational therapy.

## Website Structure

- `index.html` - Main website page
- `styles.css` - Stylesheet for the website

## Viewing the Website

To view the website locally:

1. Clone this repository
2. Open `index.html` in your web browser

Alternatively, you can serve it using any web server:

```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (http-server)
npx http-server
```

Then navigate to `http://localhost:8000` in your browser.

## Project Components

The website includes information about:

- **Project Overview**: Introduction to motion capture in occupational therapy
- **Objectives**: Key goals including data collection, analysis, visualization, and clinical integration
- **Methodology**: Technical approach and tools used
- **Team Information**: Details about the UCSD Data Science Capstone team
- **Contact**: How to reach out for more information
