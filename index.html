Project Overview

This capstone project investigates how optimal transport techniques can be used to establish point-to-point correspondences between 3D human body point clouds derived from motion capture data. By modeling correspondences as transport plans, we aim to improve alignment accuracy across frames and better understand motion dynamics.

Our work focuses particularly on resolving left-right ambiguities in human body data, enabling more reliable tracking of limbs and regions over time. The project bridges mathematical theory, geometric data analysis, and practical applications in motion analysis.

Project Goals

Robust Correspondence

Develop algorithms to match regions between point clouds using optimal transport.

Left-Right Disambiguation

Introduce a 4D embedding strategy to distinguish symmetric body parts.

Evaluation Metrics

Assess accuracy using region-level ground truth labels derived from mesh data.

Scalable Framework

Create a pipeline adaptable to LiDAR-style and high-density motion datasets.

Methods

  • Point Cloud Sampling: Generate surface samples from motion capture meshes.
  • Graph Construction: Build nearest-neighbor graphs to approximate body geometry.
  • 4D Embedding: Encode left/right proximity using anchor points from foot clusters.
  • Optimal Transport Matching: Compute one-to-one correspondences between frames.
  • Performance Analysis: Compare baseline and enhanced matching accuracy.

Data

Experiments were conducted on synthetic point clouds derived from human body meshes in the AMASS motion capture collection. We sampled consistent numbers of points per frame and evaluated correspondences across walking and running sequences.

Region labels defined on mesh faces provide ground truth for measuring mapping accuracy, enabling quantitative comparison between different matching approaches.
